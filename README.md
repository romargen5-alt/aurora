# Дирекция национальных видов спорта

Веб-сайт в этно-стиле для Дирекции национальных видов спорта с админ-панелью для управления контентом.

## Структура проекта

```
national-sports-website/
├── server.js            # Express-сервер (бэкенд + API)
├── index.html           # Главная страница
├── sports.html          # Виды спорта
├── events.html          # Мероприятия
├── about.html           # О нас
├── contacts.html        # Контакты
├── css/
│   ├── style.css        # Основные стили
│   ├── ornaments.css    # Этнические орнаменты
│   └── animations.css   # Анимации
├── js/
│   └── main.js          # Фронтенд JavaScript
├── admin/
│   ├── index.html       # Админ-панель (дашборд)
│   ├── login.html       # Страница входа
│   ├── admin.css        # Стили админки
│   └── admin.js         # Логика админки
├── data/
│   └── initial.json     # Начальные данные
└── package.json
```

## Особенности

- **Этно-стиль**: Цветовая палитра (терракота, золото, зелень), этнические орнаменты и паттерны
- **Адаптивный дизайн**: Корректное отображение на всех устройствах
- **Анимации**: Плавные появления при скролле, анимированные счётчики
- **5 страниц**: Главная, Виды спорта, Мероприятия, О нас, Контакты
- **Админ-панель**: Полное управление новостями, мероприятиями и видами спорта (CRUD)
- **REST API**: Бэкенд на Express с JSON хранилищем данных

## Админ-панель

Доступна по адресу `/admin/login.html`

**Логин по умолчанию:**
- Логин: `admin`
- Пароль: `admin123`

### Возможности:
- Добавление, редактирование и удаление новостей
- Управление мероприятиями (с категориями и тегами)
- Управление видами спорта
- Публикация/снятие с публикации контента
- Дашборд со статистикой

## Запуск

```bash
npm install
npm start
```

Сервер запустится на http://localhost:3000

### Переменные окружения (необязательно)

- `PORT` — порт сервера (по умолчанию 3000)
- `ADMIN_USER` — логин администратора (по умолчанию admin)
- `ADMIN_PASS` — пароль администратора (по умолчанию admin123)
- `SESSION_SECRET` — секрет для сессий

## Виды спорта

- Борьба курэш
- Стрельба из лука
- Конные скачки (Байга)
- Мас-рестлинг
- Тогуз коргоол
- Хапсагай

## API

### Публичные эндпоинты
- `GET /api/news` — список новостей
- `GET /api/events` — список мероприятий (с фильтром `?category=`)
- `GET /api/sports` — список видов спорта

### Админские эндпоинты (требуют авторизации)
- `POST/PUT/DELETE /api/admin/news/:id`
- `POST/PUT/DELETE /api/admin/events/:id`
- `POST/PUT/DELETE /api/admin/sports/:id`
