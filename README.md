# Дирекция национальных видов спорта

Веб-сайт в этно-стиле для Дирекции национальных видов спорта — организации, занимающейся сохранением, развитием и популяризацией традиционных видов спорта.

## Структура проекта

```
national-sports-website/
├── index.html          # Главная страница
├── sports.html         # Виды спорта
├── events.html         # Мероприятия
├── about.html          # О нас
├── contacts.html       # Контакты
├── css/
│   ├── style.css       # Основные стили
│   ├── ornaments.css   # Этнические орнаменты
│   └── animations.css  # Анимации
├── js/
│   └── main.js         # JavaScript
└── README.md
```

## Особенности

- **Этно-стиль**: Цветовая палитра (терракота, золото, зелень), этнические орнаменты и паттерны
- **Адаптивный дизайн**: Корректное отображение на всех устройствах
- **Анимации**: Плавные появления при скролле, анимированные счётчики
- **5 страниц**: Главная, Виды спорта, Мероприятия, О нас, Контакты
- **Без зависимостей**: Чистый HTML/CSS/JS, только Google Fonts

## Виды спорта на сайте

- Борьба курэш
- Стрельба из лука
- Конные скачки (Байга)
- Мас-рестлинг
- Тогуз коргоол
- Хапсагай

## Запуск

Откройте `index.html` в браузере или запустите любой локальный сервер:

```bash
# Python
python3 -m http.server 8000

# Node.js (npx)
npx serve .
```
